System Architecture & Rules

1. Adaptive Difficulty (3D Array Bank):

Questions are indexed via Question[Category][Difficulty][Index]. Scoring 2 consecutive correct answers elevates difficulty (EASY ➔ MEDIUM ➔ HARD). An incorrect answer drops difficulty level down.

2. Engineering Curriculum Categories:

Includes Java & OOP, Python, Data Structures & Algorithms (DSA), Computer Science Core (OS, DBMS, Networks), Engineering Mathematics, and General Tech Knowledge.

3. Custom Question Count & Zero Repeats:

Enter any custom number of questions. Questions are sampled randomly from unasked pools to ensure no repetition.

4. Anti-Cheat Security:

Submitting an answer in < 2.0s triggers TooFastAnswerException and logs an anti-cheat violation.

5. HashMap Progress Tracking & Report Export:

Category performance stats are aggregated in HashMaps, calculating accuracy rates, identifying Strongest & Weakest subjects, and exporting a formatted quiz_summary_report.txt file.
